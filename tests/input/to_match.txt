# TNA iMPACT! - scripted path from the attract loop into a playable match.

# Times are seconds after the game first polls the pad. The opening movie and

#   attract -> START -> EXHIBITION (default) -> STANDARD MATCH (default)
#   -> controller select (P2 = AI) -> player select (Samoa Joe vs AJ Styles)
#   -> arena select (Orlando, default).
